# Doppler Visualizer

A small C and raylib program that visualizes sound waves emitted by a moving source. The white circle is the source; expanding rings represent the waves it emits.

## Requirements

- C compiler (such as GCC)
- [raylib](https://www.raylib.com/), including its development libraries
- Linux/X11 libraries used by raylib

## Build and run

```sh
make
make run
```

## Controls

Use `W`, `A`, `S`, and `D` to move the source. Close the window to quit.

## Clean

```sh
make clean
```
